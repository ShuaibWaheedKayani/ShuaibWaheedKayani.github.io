# Shuaib Waheed — AI Engineer Portfolio

GitHub Pages portfolio covering Python, ML, deep learning, LLMs, model training and fine-tuning, agentic AI, n8n, Make, Zapier, and GoHighLevel.

## Publish
1. Create a public repository named exactly `shuaibwaheed.github.io`.
2. Upload all files and folders in this starter to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
5. Visit `https://shuaibwaheed.github.io` after deployment.

## Before publishing
- Replace placeholder contact links.
- Keep only tools you have actually used; label developing skills honestly.
- Replace suggested project slots with completed projects and evidence.
- Add screenshots, demo links, evaluation results, and sanitized exports.
- Never publish credentials, API keys, private webhook URLs, or client data.
